# astrbot_plugin_lolmatch

英雄联盟职业赛事助手：查赛程、查赛果、查单场逐局数据，订阅联赛后按时段推送。

| 项 | 值 |
|---|---|
| 插件名 | `astrbot_plugin_lolmatch` |
| 版本 | v1.1.0 |
| AstrBot | `>=4.16,<5` |
| 数据源 | 玩加赛事 scoregg（默认） / PandaScore（备选） |
| 依赖 | 仅 `aiohttp`（AstrBot 内置） |

---

## 它解决什么

群里问「今天有没有比赛」「刚才谁赢了」的时候，不需要有人去开网页截图。三条只读指令解决查询，一条订阅解决「不想每天问」。

推送侧的两个实际问题也一起处理了：

- **不想被半夜打扰**：可提醒时段支持 `工作日 09:00-18:00`、`22:00-06:00` 跨零点，工作日判断含法定节假日与调休。
- **需要有人被叫到**：支持 `@全体` 与 `@指定人`；平台拒绝时自动降级为普通消息，内容照常送达。

## 安装

```bash
cd AstrBot/data/plugins
git clone https://github.com/szjmhxd/astrbot_plugin_lolmatch
```

WebUI 重载插件即可，无需额外依赖。首启动会补三样缓存（工作日日历、英雄中文名、英雄编号映射），大约 4 个请求，之后都走本地文件。

## 指令

全部挂在 `/lol` 下，子指令用中文。

### 查询

| 指令 | 说明 |
|---|---|
| `/lol 今日` | 今天的比赛 |
| `/lol 本周` | 未来 7 天 |
| `/lol 联赛` | 进行中 / 即将开始的联赛与 ID |
| `/lol 联赛详情 <联赛ID>` | 该联赛近期场次，从这里拿比赛 ID |
| `/lol 详情 <比赛ID>` | 单场逐局数据：比分、击杀、推塔、小龙/大龙/先锋/巢虫/远古龙、BP 禁选、双方各 5 人的英雄、KDA、经济、伤害占比、MVP / 背锅 |
| `/lol 详情 <比赛ID> <局号>` | 只看其中一局，BO5 时不刷屏 |

### 订阅推送

| 指令 | 说明 |
|---|---|
| `/lol 订阅 <联赛ID>` | 每晚推送当日战果 + 次日赛程 |
| `/lol 取消订阅 <联赛ID>` | — |
| `/lol 订阅列表` | — |
| `/lol 测试推送` | 立刻按当前设置发一条，验证 @ 和排版（管理员） |

### 提醒设置

| 指令 | 说明 |
|---|---|
| `/lol 提醒` | 看当前设置 |
| `/lol 提醒 全体` | 推送时 @全体成员 |
| `/lol 提醒 关` | 不 @ 任何人 |
| `/lol 提醒 加 @某人` | 加入 @ 名单（@ 不出来可直接写用户 ID） |
| `/lol 提醒 删 @某人` | — |
| `/lol 提醒 列表` | 看 @ 名单 |
| `/lol 提醒 时段 加 工作日 09:00-23:30` | 添加可提醒时段 |
| `/lol 提醒 时段 列表` / `删 <序号>` / `清` | — |
| `/lol 提醒 时间 23:00` | 每晚推送时刻 |

### 数据源

| 指令 | 说明 |
|---|---|
| `/lol 设置 源 scoregg\|pandascore` | 只影响当前会话 |
| `/lol 设置 key <PandaScore Key>` | 当前会话专用 Key，不回显 |
| `/lol 设置 清key` | 回落到插件配置里的默认 Key |
| `/lol 状态` | 当前会话实际生效的配置 |

## 提醒规则

### 时段的写法

| 写法 | 含义 |
|---|---|
| `08:00-23:30` | 每天都在这个区间 |
| `工作日 09:00-18:00` | 只在这个区间，且当天是工作日 |
| `休息日 10:00-22:00` | 只在这个区间，且当天是休息日 |
| `22:00-06:00` | 跨零点，夜里也算 |
| 多个时段 | 任意一个命中就提醒 |

### 工作日怎么判

数据来自 [NateScarlet/holiday-cn](https://github.com/NateScarlet/holiday-cn)，规则三条：

1. 在「调休上班」里 → 工作日，哪怕是周六；
2. 在「放假」里 → 休息日，哪怕是周三；
3. 其余按星期几：周一到周五工作日。

次年安排一般 10 月底到 11 月才公布，公布前该年数据是空的。插件在开放日（默认 `11-01`，可配）起每 30 分钟试一次，拿到就停手；没拿到时按纯周末规则估算，`/lol 状态` 会显示「未就绪」。

### @ 的权限问题

`@全体` 需要机器人是群管理员，这一点各平台不一样，AstrBot 也没有统一的权限查询接口。

实现方式是**先试再降级**：带 @ 发送，平台拒绝就立刻重发不带 @ 的版本。所以你看到的现象是「消息收到了，但没有 @」——不是配置错了，是权限不够。`/lol 测试推送` 可以直接验证。

## 配置项

| 键 | 类型 | 默认 | 说明 |
|---|---|---|---|
| `enabled` | bool | `true` | 总开关 |
| `default_provider` | string | `scoregg` | 默认数据源 |
| `pandascore_token` | string | 空 | 全局默认 PandaScore Key |
| `allow_session_token` | bool | `true` | 允许会话覆盖 Key |
| `push_time` | string | `23:00` | 默认推送时刻 |
| `default_windows` | string | `08:00-23:30` | 默认可提醒时段，留空 = 全天 |
| `default_mention` | string | `none` | `none` / `all` / `list` |
| `default_mention_targets` | list | 空 | 默认 @ 名单（用户 ID） |
| `admin_ids` | list | 空 | 留空 = 不限制 |
| `subscribe_limit` | int | `3` | 单会话可订阅联赛数 |
| `week_match_days` | int | `7` | 「本周」展示天数 |
| `max_matches_per_day` | int | `20` | 每天最多显示场次 |
| `request_timeout` | int | `12` | 接口超时（秒） |
| `holiday_fetch_date` | string | `11-01` | 次年节假日开放日 |

会话级设置存在 `data/plugin_data/astrbot_plugin_lolmatch/sessions.json`，不写插件自身目录。

## 数据源

### 主：玩加赛事（scoregg）

- 无需鉴权、无需付费，赛程赛果一次请求全带；
- 单场详情先取比赛主体（比分、逐局结果），再按局去 CDN 取明细（BP、推塔、选手经济伤害）；明细取不到时自动退回精简版，不会因为补数据失败连详情都不给；
- 中文队名、中文联赛名。

### 备：PandaScore

- 字段规范、有服务承诺、限流口径明确（免费档 1000 请求/小时）；
- 免费档只有赛程赛果，**逐局数据在 400€/月 的 Historical 档**，所以切过去之后「详情」只能看比分；
- Key 申请方法见 [docs/pandascore.md](docs/pandascore.md)。

切换逻辑：当前源抛可重试错误时自动换另一个；`pandascore` 没配 Key 就跳过，不会卡住查询。

### 合规与风险

写清楚比藏着好。

| 项 | 情况 |
|---|---|
| 付费要求 | 无。scoregg 接口不需要注册、不需要 Key、没有付费墙 |
| robots.txt | `User-agent: *` 且无任何 `Disallow`，全站不禁爬 |
| 服务条款 | 站点只提供《隐私政策》（讲用户数据），没有约束第三方调用 API 的条款 |
| 授权性质 | **没有书面授权**。这是站点前端在用的内部接口，属于事实上的公开接口 |
| 稳定性 | 无文档、无 SLA，字段和路径随时可能变。这是选它做默认而不是唯一的原因 |
| 图片版权 | 队标、英雄图标版权属腾竞 / 拳头。本插件**不转发任何图片**，纯文本输出，避免外链与二次分发风险 |
| 商标 | 插件不使用 LPL / 世界赛官方 logo，插件名与图标均为自绘 |
| 商用 | 如果要商用，自行评估并联系站点方。本插件按 MIT 开源，不对数据合法性作任何担保 |

请求频率上，一个会话一天最多 2 次定时请求（当日 + 次日），查询指令按需触发，不构成压力。

## 已知限制

- **个别英雄名会显示 `—`**：新英雄的图标路径是纯数字（`champion_new/543.png`），源站没给英文名。插件会用「英雄编号 → 英雄名」的映射反查，映射从历史比赛里学，查得越多越全。
- **BP 里偶尔出现 `？`**：禁选只给了图标，源站数字编号和 Data Dragon 的编号是两套（同一个 101，一边是辛德拉、一边是卡尔玛），只能靠平时从选手数据里学。认出来的不足 3 个时整行不显示，不拿猜的名字糊弄。
- **联赛详情只看当前一周**：源接口按周返回，超过一周的历史要去网页查。
- **PandaScore 备选看不到逐局数据**：免费档限制，不是代码问题。
- **纯文本，没有图片卡片**：赛程的价值是「谁打谁、几比几、几点」，画成图只增加一次渲染和一次上传。

## 目录结构

```
astrbot_plugin_lolmatch/
├── main.py               插件入口：指令路由、推送循环
├── metadata.yaml
├── _conf_schema.json
├── requirements.txt
├── lol/
│   ├── models.py         内部数据模型（换源不改上层）
│   ├── provider.py       数据源门面与自动切源
│   ├── scoregg.py        玩加赛事
│   ├── pandascore.py     PandaScore
│   ├── champions.py      英雄中文名 + 编号映射
│   ├── workday.py        工作日日历
│   ├── windows.py        可提醒时段
│   ├── store.py          会话设置与订阅
│   ├── notify.py         发送与 @ 策略
│   └── render.py         纯文本排版
└── docs/pandascore.md
```

`lol/` 包不依赖 AstrBot 的运行时对象，可以脱离框架单独跑（用于测试与排查）。
