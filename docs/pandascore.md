# PandaScore Key 获取与配置

备选数据源。只有你想摆脱「依赖站点内部接口」这件事时才需要它，默认的 scoregg 不需要任何 Key。

---

## 一、它免费能给什么

| 能力 | 免费 Fixtures 档 | Historical（400€/月起） | Live（1000€/月起） |
|---|---|---|---|
| 赛程 / 赛果 / BO 数 | ✅ | ✅ | ✅ |
| 战队、联赛元信息 | ✅ | ✅ | ✅ |
| 逐局数据、选手统计 | ❌ | ✅ | ✅ |
| 实时帧 / 事件流 | ❌ | ❌ | ✅ |
| 请求配额 | **1000 次/小时** | 10000 次/小时 | 10000 次/小时 |

结论：免费档能替代「今日 / 本周 / 联赛」，**替代不了「详情」**。切过去之后 `/lol 详情` 只会显示比分，不显示 KDA。这是套餐差异，插件已经按这个前提降级显示。

一个群机器人一天最多用 2 次定时请求 + 若干次查询，1000 次/小时远够。插件内部还对同一 URL 做了 60 秒缓存。

---

## 二、拿到 Key

1. 打开 <https://app.pandascore.co/signup>，用邮箱注册。不需要信用卡。
2. 登录后进入 Dashboard。
3. 在账号 / 设置区域找到 **Access Token**（有时显示为 API Token）。这是一串以随机字符开头的长字符串。
4. 复制它。**不要在公开频道里发出来**——等同于密码。

如果你要正式产品化（对外提供服务），需要走 `Register Project` 申请付费档；个人或小群自用停在免费档即可，条款允许非博彩类用途。

---

## 三、填到哪

两种粒度，按需选。

### 全局默认（推荐，一次配好所有会话）

AstrBot WebUI → 插件 → `LOL 赛事助手` → 配置：

```
PandaScore API Key（默认值）: <你的 Key>
```

对应 `_conf_schema.json` 里的 `pandascore_token`。

### 会话单独 Key（多人共用一个机器人时用）

```
/lol 设置 key <你的 Key>
```

只对当前群 / 私聊生效，其他会话仍用全局 Key。这样几个群可以分摊各自的配额。

- 关闭「允许会话自定义 Key」（配置项 `allow_session_token`）后，这条指令会被拒绝；
- `/lol 设置 清key` 清除本会话 Key，回落到全局；
- Key 不会回显，`/lol 状态` 只显示「已设置 / 未设置」。

### 切到 PandaScore

```
/lol 设置 源 pandascore
```

或不改会话，直接把配置里的 `default_provider` 改成 `pandascore`。

切回：`/lol 设置 源 默认`。

## 四、验证 Key 是否可用

命令行直接打一次，看到 JSON 就是通的：

```bash
curl -s "https://api.pandascore.co/lol/tournaments/upcoming?per_page=1" \
  -H "Authorization: Bearer <你的 Key>"
```

返回 `401` 是 Key 错；`429` 是配额打满（免费档 1000/小时）；`200` 但空数组说明当前没有即将开始的赛事，Key 本身没问题。

插件侧用 `/lol 状态` 看「数据源」和「PandaScore Key」，再用 `/lol 今日` 实际查一次。

---

## 五、常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| `PandaScore Key 无效或已过期` | 401 | 重新复制 Key，注意别带空格 |
| `触发限流（免费档 1000 次/小时）` | 429 | 等一小时，或换会话 Key 分摊 |
| 详情只有比分没有 KDA | 免费档不含逐局数据 | 属预期，需要就上付费档 |
| 队名是英文 | PandaScore 只有英文 | 想中文队名就用 scoregg |
| 时间差了 8 小时 | 时区 | 插件已按本地时区换算，若仍异常请检查系统时区 |

## 六、要不要真的切

| 场景 | 建议 |
|---|---|
| 只是群友查赛程赛果，要中文 | 留在 scoregg，不用配 Key |
| 担心站点接口哪天挂掉 | 配一个免费 Key 放兜底，平时不用切 |
| 站点接口已经挂了，查询报错 | 立刻 `/lol 设置 源 pandascore`，赛程赛果照常 |
| 需要逐局技术统计 | 留在 scoregg，PandaScore 这条路要付费 |
